## Verdicts

Classify every scenario in the checklist as exactly one of:

- SATISFIED - code on this branch implements the scenario's behaviour
- PARTIAL - some of the behaviour is implemented, the rest is missing
- CONTRADICTED - the code does something the scenario forbids or the opposite of what it requires
- NOT ADDRESSED - nothing on this branch implements it

Delta operations change what counts as satisfied:
- [ADDED] - the behaviour must exist on this branch
- [MODIFIED] - the new behaviour must exist and the superseded behaviour must be gone
- [REMOVED] - satisfied when the behaviour and its tests are gone, not when they are merely unused
- [RENAMED] - the behaviour is unchanged; only its name moves

## Citation discipline

Every SATISFIED and PARTIAL verdict MUST cite `file:line` for code you opened
and read, and the cited line must be the code that implements the scenario. A
matching name, a call site, or a plausible-looking function is not evidence.

If you cannot cite a line, the verdict is NOT ADDRESSED - report it as such
rather than as satisfied. This rule is the point of this review: an uncited
"satisfied" is how spec drift ships.

For NOT ADDRESSED, cite the search you ran that came back empty, so the executor
can repeat it.

## Scope

- Judge only against the checklist above. Defects unrelated to a requirement
  belong to the quality agent; task-list bookkeeping belongs to the tasks agent.
- Untested behaviour is still satisfied behaviour - missing tests are the testing
  agent's finding, not a conformance gap.
- If the checklist says it was truncated, read the delta spec files listed above
  for the rest, and say in your report that it was truncated.

## What to Report

For each scenario that is not SATISFIED:
- Requirement: its number and name from the checklist
- Scenario: its name
- Verdict: partial / contradicted / not addressed
- Evidence: `file:line` you read, or the search that found nothing
- Severity: critical for a contradicted or unimplemented ADDED requirement,
  major for a partial one, minor for a cosmetic divergence
- Fix: what is missing, in terms of the requirement's own wording

scenarios are satisfied, partial, contradicted, and not addressed.
